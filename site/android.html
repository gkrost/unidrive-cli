Android

UniDrive on Android.

The Android app is in development. There is no public APK.

Release status. The v0.0.3 release provides the Java CLI. A public Android APK is not part of that release, and the Android source is not yet public.

What exists

The app shares the core, sync and provider modules of the UniDrive engine through Gradle composite builds. It connects to OneDrive (browser sign-in with OAuth and PKCE) and Internxt (email, password and a two-factor code when required). It lists synced files and tracks remote-only items with placeholder sidecar files, keeping sync state in an SQLite database on the device. A sync worker that runs the shared engine is built.

What does not exist yet

  • Scheduling the sync worker in the background is not wired up.
  • Local change detection with FileObserver is planned, not built.
  • Gallery insertion code exists, but the app does not call it yet.
  • The Activity tab is a placeholder.

For what you can run today, see the install page.
