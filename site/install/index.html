Installation

Get started with UniDrive.

UniDrive is pre-release software. You can build the Linux engine from source while packaged releases are being prepared.

Package channels are not ready. Apt, dnf, AUR and tarball downloads are not yet published. Do not configure these channels until release instructions are available here. The signed Java jar of v0.0.3 is available now (below).

Signed Java jar (v0.0.3)

Requires Java 25 or newer. Import the release key, then check the fingerprint before you trust it. Every step runs only if the one before it succeeded, so a bad signature or checksum stops the install.

ver=0.0.3
base=https://github.com/gkrost/unidrive-cli/releases/download/v${ver}
for f in unidrive-${ver}.jar unidrive-${ver}.jar.asc unidrive-${ver}.jar.sha256 unidrive-${ver}.jar.sha256.asc; do curl -fsSLO ${base}/${f} || break; done

curl -fsSL https://unidrive.krost.org/install/unidrive-releases.gpg | gpg --import
gpg --fingerprint releases@unidrive.krost.org

gpg --verify unidrive-${ver}.jar.sha256.asc unidrive-${ver}.jar.sha256 && gpg --verify unidrive-${ver}.jar.asc unidrive-${ver}.jar && sha256sum --ignore-missing -c unidrive-${ver}.jar.sha256 && java -jar unidrive-${ver}.jar --help

Build from source

The engine requires a JDK to build. Linux installation and the user service have additional prerequisites. Follow the current build instructions and installer guide for requirements and setup.

Release signing key

The release public key is provided at its existing URL. Its fingerprint is:

C114 9DEF CF77 CF57 EB78 B3FB 749F EDA7 6CB3 6B2F

Before trusting a key or a package, confirm the fingerprint through an independent trusted channel. A key and fingerprint published on the same site do not independently authenticate each other. Instructions for signed packages will be published when those releases are available.
