Installation

Get started with UniDrive.

UniDrive is pre-release software. You can build the Linux engine from source while packaged releases are being prepared.

Package channels are not ready. Apt, dnf, AUR and signed downloads are not yet published. Do not configure these channels until release instructions are available here.

Build from source

The engine requires a JDK to build. Linux installation and the user service have additional prerequisites. Follow the current build instructions and installer guide for requirements and setup.

Release signing key

The release public key is provided at its existing URL. Its fingerprint is:

C114 9DEF CF77 CF57 EB78 B3FB 749F EDA7 6CB3 6B2F

Before trusting a key or a package, confirm the fingerprint through an independent trusted channel. A key and fingerprint published on the same site do not independently authenticate each other. Signed package instructions will be published when releases are available.
