01 / The engine

Built around your files.

A shared engine handles cloud connections and sync. Platform clients use it to bring those files closer to the tools you already use.

01

Two-way sync

Changes move between your local files and your configured cloud account.

02

One engine, multiple providers

Internxt and OneDrive are the focus. The repository also contains S3 and Dropbox providers.

03

Open by design

Read the source, inspect how it works, and contribute. The engine collects no telemetry.

02 / Platforms

One core, different surfaces.

The engine and its platform integrations are at different stages. UniDrive is pre-release software.

LINUX

Daemon and CLI

Build the engine from source and run it as a user service. A separate FUSE integration provides a mount.

WINDOWS

Desktop integration

A Windows client uses the engine to connect cloud files with Explorer.

ANDROID

Planned

Android is a future platform for the shared engine; it is not available today.
